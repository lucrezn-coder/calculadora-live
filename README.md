# Calculadora Live

Cotizador interactivo para unidades en preventa de Loreta, Cancún. Proyecto estático: HTML, CSS y JavaScript en un solo archivo, con los recursos visuales incluidos.

## Uso local

Abre `index.html` en un navegador. No requiere instalación ni dependencias.

## Modificar

Edita `index.html` para cambiar interfaz, cálculos, inventario, precios o supuestos. Los recursos visuales están en esta carpeta. Puedes crear un fork y proponer cambios mediante pull request.

Los precios, inventario, promociones, rentas y proyecciones son orientativos y deben confirmarse con LIVE antes de usarse para una oferta.
